# 烦烦 Paper Trade · 前瞻实验台账

**看板**: https://somazz88.github.io/paper-trade/

## 现在跑的是什么（2026-08-31 起 · 第 2 期）

一个三条件筛选器（波动率压缩 ap126 + 距 60 日高 ≤5% + 20 日跑赢 SPY）每天扫 49 只票，
**新进入状态（onset）的票才算信号**。每条信号腿打三层标签，分层读数：

- **规则组（全跟）** —— 每条 onset 都开，无人筛选。它是尺子，永不掺人。
- **烦烦组** —— 规则之上，AI 分析师逐条挑（CE 趋势 / 板块轮动 / 载体贵不贵 / 财报距离），理由必录。
- **终审组** —— 烦烦挑中的里面，人再拍最终板。

三个读数各答一个问题：烦烦组 vs 规则∖烦烦 = AI 判断的增量；终审组 vs 烦烦∖终审 = 人的否决权的增量；
规则组 = 空白对照。每腿另标注 CE 方向、动量分位、当日全场在状态数（regime），攒够样本分组检验。

出场统一锁死（两组比较才有效）：权利金 −50% 硬止损 · 无固定止盈 · 最多 20 个交易日。

## 🔴 为什么这个台账现在格外诚实

这个筛子曾在回测里给出 +15.6pp 的出样本净胜率 —— **后来被我们自己证伪了**：
换到一个无后见的票池（NASDAQ-100 的 2025-01 时点成分）重跑，效应塌缩到 **+0.3pp ≈ 零**。
原因是回测票池是事后组装的，带生存者偏差；train/test 切分防不住票池层面的后见。

**所以现在的先验是「筛子 ≈ 无 edge」，本台账是它唯一干净的前瞻检验** ——
不是「已验证策略」的展示，是「这东西到底有没有用」的第一手证据，涨跌都记，拒绝的也跟踪。

## 第 1 期（2026-08-28 开仓 · 载体对照 · 跑完为止）

同一批信号用两种载体同时开仓，测**载体本身**值多少：

| 组 | 载体 | 出场规则 |
|---|---|---|
| A | 1 个月 ATM call | 权利金 −50% 硬止损 · 最多 20 个交易日 |
| B | 永续合约 3x | CE 动态线（最高价 14 周期 − 2.0×ATR，棘轮只上不下） |

核心一格是 C 组（COIN / MSTR / PLTR）：同日同标的同方向、只有载体不同。
回测提示期权单笔中位 −40.4% vs perp +10.11%（⚠️ 同一个带偏票池所测——**差值**因同路径对比大体抗偏，
绝对值别引用），那 50 个百分点是不是真的，看它们。
perp 腿另有**周末哨兵**：正股闭市时读离岸股票永续的 24/7 真实报价，穿越止损线按观测价记，
不用周一跳空价——修掉「周末盲区」低估尾部风险的偏差。

## 口径与免责

- 期权按 **ask 进 / bid 出** 计价，是最保守的一端
- perp P&L 为**保证金口径**，已含杠杆，**未计**资金费与滑点
- 数据每 5 分钟由本地程序从券商快照生成后推送；页面每 60 秒重取
- **模拟仓，非真实成交。** 历史回测数字已按上文说明降级处理。本仓库为方法记录，**不构成投资建议**。
