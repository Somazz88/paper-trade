# 烦烦 Paper Trade · 载体对照实验

**看板**: https://somazz88.github.io/paper-trade/

## 这是什么

同一批选股信号，用两种载体同时开模拟仓，看载体本身值多少：

| 组 | 载体 | 出场规则 |
|---|---|---|
| A | 1 个月 ATM call | 权利金 −50% 硬止损 · 不设固定止盈 · 最多 20 个交易日 |
| B | 永续合约 3x | CE 动态线（最高价 14 周期 − 2.0×ATR，棘轮只上不下） |

**核心一格是 C 组**（COIN / MSTR / PLTR）—— 这三只两组都持有，同一天、同一标的、同一方向，
**只有载体不同**。回测量到期权单笔中位 −40.4% vs perp +10.11%，那 50 个百分点是不是真的，看它们。

## 复盘口径（开仓前定死，不许事后挑）

- **A** 期权 10 只 → 筛子在期权载体上的出样本表现
- **B** perp 5 只 → 新筛子在 perp 载体上的表现
- **C** 两组都在的 3 只 → **测载体本身**
- **D** perp 独有的 NVDA / MSFT → 测「ap126 放宽 + 基准换 QQQ」这两处改动

另记：标「推荐」的单列，测主观判断；**标「我拒绝」的照样跟踪** —— 拒绝的理由如果从不被检验，
就永远不知道它对不对。

## 口径与免责

- 期权按 **ask 进 / bid 出** 计价，是最保守的一端
- perp P&L 为**保证金口径**，已含杠杆，**未计**资金费与滑点
- 数据每 5 分钟由本地程序从券商快照生成后推送；页面每 60 秒重取
- **模拟仓，非真实成交。** 所引历史胜率来自回测，不代表真实结果。本仓库为方法记录，**不构成投资建议**。
